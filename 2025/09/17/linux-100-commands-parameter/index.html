〇、 忘记命令查找方法

  1. apropos – 法语 “à propos”，意思是“关于、相关”

apropos 关键词

# 搜索与 "list" 相关的手册页
apropos list

# 只找描述中完整包含 "host" 这个词的条目，排除 "ghost" 等
apropos -e host

# 查找同时涉及 "list" 和 "directory" 的手册页
apropos -a list directory

# 搜索以 "zip" 开头的相关命令
apropos '^zip'

# 搜索包含 "note" 或 "cloak" 或 "info" 的 zip 相关项
apropos 'zip(note|cloak|info)'

printf – print formatted
格式化打印/输出

# printf [格式字符串%s 数字] [参数...] 

printf '%s\n' *.log > matched-logs.txt 

printf '%s\n' "$PATH" | tr ':' '\n'

# printf 打印，
# %s：代表一个字符串（String）占位符，格式化字符串开始
# \n：代表换行符（Newline）
# 用单引号把%s\n包裹，意思是将格式字符串原样交给 printf
# $PATH 是shell里预先指定的变量，用双引号不会阻止变量展开，单引号就会

printf 'HOME=%s\nUSER=%s\n' "$HOME" "$USER" 
# 模板格式： 'HOME=%s\nUSER=%s\n'
# 参数变量： "$HOME" "$USER" 
# printf 的工作方式是：从左到右扫描格式字符串，每遇到一个 %s，就从后面的参数列表里取一个字符串填进去，所以，和模板字符串写法不同
# 如 按照JS，python的写法，则是：printf "HOME=$HOME\nUSER=$USER\n" ，和上面的C语言模板，参数分开很不同，如果$USER 的值里不小心包含了一个百分号 %，则printf 会把它当成格式指令去解析，会输出错乱甚至安全问题

ln – link
软链接，硬链接

# ln 用于创建链接，基本语法是：
 
# ln [选项] 源 链接名

# 创建硬链接（不加选项）：

ln links/source.txt links/hard-link.txt

# 两个文件名指向同一份文件数据（同一个 inode）。删除其中一个名称，另一个仍可访问数据。

# 创建符号链接（加 -s）：

ln -s source.txt links/symbolic-link.txt

#  符号链接保存目标路径。相对路径是相对于符号链接所在目录解析的；如果目标被删除或移动，链接就会失效。

# 常见参数
-s    #  创建符号链接。
-f    #  目标链接名已存在时，先移除它再创建。
-i    #  目标链接名已存在时，先询问是否覆盖。
-v    #  显示创建链接的过程。
-n    #  处理指向目录的符号链接时，不将其当作目录处理，常与 -f 一起用。

#  例如：
ln -sv source.txt links/symbolic-link.txt

# 通过readlink 命令来显示符号链接内部存储的路径
readlink links/symbolic-link.txt

# 用 find 的 -xtype l 查找失效的符号链接。会列出目标不存在的符号链接，在实目录中运行： 
find . -xtype l


用test单独检查某个链接：
test -L links/symbolic-link.txt && echo "链接对象存在"
test -e links/symbolic-link.txt || echo "目标不存在，链接已失效"  

# -L 检查符号链接本身是否存在；-e 检查链接指向的目标是否存在

三、搜索与查找

  1. find – (无缩写)
    按条件查找文件 

    # 模糊匹配（通配符）
find . -name "*.txt"         # . 指搜索起点，当前目录（包含所有子目录）
find . -name "*.conf"        # 所有 .conf 文件
find . -name "app*"          # 以 app 开头的文件
find . -iname "APP.CONF"     # -iname 忽略大小写

# 按类型查找
find . -type f -name "*.log"   # 只找普通文件
find . -type d -name "config"  # 只找目录
find . -type l                 # 只找符号链接

# 按大小查找
find . -size +100M            # 大于 100MB 的文件
find . -size -10k             # 小于 10KB 的文件
find . -size +500M -size -1G  # 500MB 到 1GB 之间

# 按时间查找

find . -mtime -7        # 7 天内修改过的文件
find . -mtime +30       # 30 天前修改过的文件
find . -mmin -60        # 60 分钟内修改过
find . -atime -1        # 1 天内访问过
find . -newer app.conf  # 比 app.conf 更新的文件

#  按用户/权限
find . -user www-data          # 属于 www-data 的文件
find . -perm 777               # 权限正好是 777
find / -perm -4000             #设置了 SUID 的文件（安全审计常用）


# 找到后执行操作
find . -name "*.log" -exec rm {} \;               # 删除所有 .log 文件
find . -name "*.tmp" -exec rm -i {} \;            # 删除前逐个确认
find . -type f -exec chmod 644 {} \;              # 批量改权限
find . -name "*.conf" -exec grep -l "8080" {} \;  # 在结果里搜内容

    打包/解包

tar -czvf [压缩包名字] -T [清单文件名字]

# c：create 创建
# z: gzip 压缩格式
# v: 详细模式，用于查看进度
# f: 指定文件名
# T: --files-from, 从指定的文本文件中读取要打包的各个文件，按清单打包这些目录及其内容


tar -xvf a.tar # 解压

# 从backup.tar.gz提取指定文件：config/app.conf
tar -xzf backups/backup.tar.gz config/app.conf 
# -x: 即extract（提取），如果没有在命令末尾指定具体路径，tar 会解压全部内容



# 列出压缩归档中的内容，并把列表保存到 backup-contents.txt，不会解压文件

tar -tzvf backups/backup.tar.gz > backup-contents.txt
# -t：列出归档中的文件和目录，不解压。
# -z：通过 gzip 处理压缩归档。
# -v：显示详细信息，例如权限、大小和路径
# >： 重定向运算符  将命令输出保存到文件

五、用户与权限

  1. whoami – (无缩写)
    显示当前用户

  2. umask – (user mask)
    用于设定“新建文件/目录默认要扣掉哪些权限”的遮罩
    只管未来新建的东西。对老文件无效，改老文件用 chmod
    在这个终端（这个 shell 进程）里，接下来运行的任何命令创建的文件/目录——不管建在哪个路径——都会套用指定的掩码


umask	     # 不加任何参数，直接显示当前掩码（通常是八进制，如 0022）
umask -S     # 用符号形式显示当前掩码，比如 u=rwx,g=rx,o=rx。注意：这里显示的是“允许”的权限，而不是被遮掉的权限
umask 022	 # 用八进制直接设置掩码。最常用的写法，即：从此刻起，这个 shell 里新建的一切都按 022 扣权限
umask u=rwx,g=rx,o=	# 用符号形式设置。坑点：符号里的 +/- 是相对于“当前掩码”操作的，逻辑和 chmod 相反，很容易设反


old=$(umask)
umask 027
# ... 创建文件操作 ...
umask "$old"   # 用完还原原umask值

umask高频用例

命令 新文件权限 新目录权限 适用场景
umask 022 644 (rw-r–r–) 755 (rwxr-xr-x) 系统默认值，所有人可读，仅自己可写-10
umask 027 640 (rw-r—–) 750 (rwxr-x—) 同组只读，其他人完全禁止。多用户服务器上保护隐私的常用值
umask 077 600 (rw——-) 700 (rwx——) 完全私密。适合密钥、敏感配置、个人服务器-10
umask 002 664 (rw-rw-r–) 775 (rwxrwxr-x) 团队协作目录，同组可写。很多发行版对普通用户默认用这个
umask 000 666 (rw-rw-rw-) 777 (rwxrwxrwx) 完全不遮。极少用，除非在受控的临时环境里测试

  4. su – substitute user

    /ˈsʌbstɪtuːt/
    v.取代；（以…）代替
    n.代用品；代替物；代替者
    web.替身；替换；替代

    切换用户 

    su root
或者
su - root #等于 su -l root，此命令一般在实际运维中使用，以获得 root 的环境变量和配置
或者
su --login root

    su root
    仅切换用户身份为 root
    用户变成 root
    当前工作目录保持不变
    大部分环境变量继承自原用户
    PATH 可能仍带有普通用户的配置
    不会读取 root 的完整登录环境

    su - root 和 su –login root ， su -l root
    此命令一般在实际运维中使用，以获得 root 的环境变量和配置
    切换为 root
    模拟 root 刚登录系统
    进入 root 的家目录（通常 /root）
    加载 root 的环境变量
    加载 /root/.bash_profile、/root/.profile 等配置
    PATH 使用 root 的 PATH

    完成后，输入 exit，会返回原来的账户

userdel -rf 用户名

  11. usermod – (user mode)
    修改已存在的用户账号属性

    常用选项参数

选项 参数说明 示例
-c <备注> 修改用户的描述/备注信息（写入 /etc/passwd） usermod -c "Test User" username
-d <登入目录> 修改用户的主目录路径 usermod -d /home/newdir username
-m 配合 -d 一起使用，将旧主目录中的文件移动到新目录中 usermod -d /home/newdir -m username
-g <群组> 修改用户的初始（基本）用户组（组名或GID） usermod -g groupname username
-G <群组> 修改用户的附加（扩展）用户组（多个用逗号隔开） usermod -G group1,group2 username
-a 配合 -G 使用（-aG），在不移除原有附加组的前提下追加新附加组 usermod -aG group1 username
-l <新用户名> 修改用户的登录名（账号名称） usermod -l newname oldname
-s <shell> 修改用户的默认登录 Shell（如 /bin/bash） usermod -s /bin/sh username
-u <UID> 修改用户的 UID 号码 usermod -u 2026 username
-L 锁定（禁用）用户账号，使其无法登录 usermod -L username
-U 解锁用户账号，恢复登录 usermod -U username
-e <YYYY-MM-DD> 设置账号的失效/过期日期 usermod -e 2026-12-31 username

    查看进程

  2. top – (无缩写)
    动态显示进程 

    top

  3. htop – (无缩写)
    更友好的进程管理工具 

    htop

  4. kill – (无缩写)
    结束进程
    （数字为对应的PID值）

    kill 1234
# 使用信号9进行强制结束进程
kill -9 1234

  5. killall – (kill all)
    按服务名结束相关进程 

    killall nginx

  6. jobs – (无缩写)
    查看后台任务，它会列出所有作业的编号、状态和命令 

    jobs

  7. fg – foreground
    例子的意思是将后台编号1的任务切换到前台运行任务
    %1 是作业号（job number）
    比如执行 %1 任务时，使用 Ctrl+Z 暂停，或者在命令末尾加上 &，任务会被暂停
    此时终端可以用来做别的事，当别的事情完成后，就可以用 fg %1 将暂停的作业重新开始

    fg %1

  8. bg – background
    将后台暂停的作业 %N 变为后台运行
    接上例，如果 %1 被 Ctrl+Z 暂停了，可以用 bg %1 让它在后台继续运行，而不是回到前台 

    bg %1

  9. uptime – (无缩写)
    查看系统运行时间和负载 

    uptime

  10. dmesg – diagnostic message
    /ˌdaɪ.əɡˈnɑː.stɪk/
    adj.诊断的;用于诊断的(对于疾病)
    判断的；用于判断的(对于问题)
    查看内核日志 

    dmesg | tail

# 把内核信息，用管道符传到grep，T：人类可读的时间戳 i: 忽略大小写， E：使用正则，"fail|error" 匹配 fail 或 error
# | tee 文件：结果既显示在屏幕上，也保存到文件
sudo dmesg -T| grep -iE "fail|error" | tee ~/project/boot_issues.txt

  11. pgrep – process grep
    像 grep 命令搜索文本那样搜索系统中的进程


pgrep nginx # 查找名为 "nginx" 的所有进程

pgrep -l ssh # 查找 "ssh" 进程并显示进程名

pgrep -x bash # 精确匹配完全名为 "bash" 的进程

pgrep -f "sshd -p 2222" # 匹配完整命令行

pgrep -u www-data # 查找用户 "www-data" 运行的所有进程

更多 ： https://www.runoob.com/linux/linux-comm-pgrep.html

sudo ufw status  # 查看状态：      （或 sudo ufw status verbose 查看详细规则）

sudo ufw default deny incoming # 禁止所有入站
sudo ufw default allow outgoing #禁止所有出站
sudo ufw allow 80  #允许某端口
sudo ufw deny 80 #禁止某端口
sudo ufw allow ssh #允许某服务
通过编号删除：先用 sudo ufw status numbered 查看规则编号，再执行 sudo ufw delete <编号>
通过规则内容删除：sudo ufw delete allow 80

grep 语法

grep [options] pattern [files]
或
grep [-abcEFGhHilLnqrsvVwxy][-A<显示行数>][-B<显示列数>][-C<显示列数>][-d<进行动作>][-e<范本样式>][-f<范本文件>][--help][范本样式][文件或目录...]
  • pattern - 表示要查找的字符串或正则表达式。
  • files - 表示要查找的文件名，可以同时查找多个文件，如果省略 files 参数，则默认从标准输入中读取数据。

常用参数：：

  • -i：忽略大小写进行匹配。
  • -v：反向查找，只打印不匹配的行。
  • -n：显示匹配行的行号。
  • -r：递归查找子目录中的文件。
  • -l：只打印匹配的文件名。
  • -c：只打印匹配的行数。

更多参数说明：

  • -a 或 –text : 不要忽略二进制的数据。
  • -A<显示行数> 或 –after-context=<显示行数> : 除了显示符合范本样式的那一列之外，并显示该行之后的内容。
  • -b 或 –byte-offset : 在显示符合样式的那一行之前，标示出该行第一个字符的编号。
  • -B<显示行数> 或 –before-context=<显示行数> : 除了显示符合样式的那一行之外，并显示该行之前的内容。
  • -c 或 –count : 计算符合样式的列数。
  • -C<显示行数> 或 –context=<显示行数>或-<显示行数> : 除了显示符合样式的那一行之外，并显示该行之前后的内容。
  • -d <动作> 或 –directories=<动作> : 当指定要查找的是目录而非文件时，必须使用这项参数，否则grep指令将回报信息并停止动作。
  • -e<范本样式> 或 –regexp=<范本样式> : 指定字符串做为查找文件内容的样式。
  • -E 或 –extended-regexp : 将样式为延伸的正则表达式来使用。
  • -f<规则文件> 或 –file=<规则文件> : 指定规则文件，其内容含有一个或多个规则样式，让grep查找符合规则条件的文件内容，格式为每行一个规则样式。
  • -F 或 –fixed-regexp : 将样式视为固定字符串的列表。
  • -G 或 –basic-regexp : 将样式视为普通的表示法来使用。
  • -h 或 –no-filename : 在显示符合样式的那一行之前，不标示该行所属的文件名称。
  • -H 或 –with-filename : 在显示符合样式的那一行之前，表示该行所属的文件名称。
  • -i 或 –ignore-case : 忽略字符大小写的差别。
  • -l 或 –file-with-matches : 列出文件内容符合指定的样式的文件名称。
  • -L 或 –files-without-match : 列出文件内容不符合指定的样式的文件名称。
  • -n 或 –line-number : 在显示符合样式的那一行之前，标示出该行的列数编号。
  • -o 或 –only-matching : 只显示匹配PATTERN 部分。
  • -q 或 –quiet或–silent : 不显示任何信息。
  • -r 或 –recursive : 此参数的效果和指定”-d recurse”参数相同。
  • -s 或 –no-messages : 不显示错误信息。
  • -v 或 –invert-match : 显示不包含匹配文本的所有行。
  • -V 或 –version : 显示版本信息。
  • -w 或 –word-regexp : 只显示全字符合的列。
  • -x –line-regexp : 只显示全列符合的列。
  • **-y **: 此参数的效果和指定”-i”参数相同。

基本用法

grep 'root' /etc/passwd     # 搜索包含 root 的行
grep -i 'error' log.txt     # 忽略大小写
grep -n 'main' file.c       # 显示行号
grep -v 'test' file.txt     # 反向匹配
grep -r 'TODO' ./src        # 递归搜索目录
grep --color=auto root /etc/passwd   # 高亮

常用正则

grep '^root' /etc/passwd    # 以 root 开头
grep 'bash$' /etc/passwd    # 以 bash 结尾
grep 'r..t' file.txt        # r+任意两字符+t
grep 'lo*ng' file.txt       # lng, long, loong
grep '[ch]at' file.txt      # cat 或 hat
grep '[^0-9]' file.txt      # 含非数字
grep -E '(foo|bar)' file.txt # foo 或 bar

组合用法

ps aux | grep nginx         # 查找进程
dmesg | grep -i usb         # 内核日志里找 USB
history | grep ssh          # 历史命令中找 ssh

-r (递归/反序) -R (递归并跟随符号链接) 扩展功能
-v (反选/详细) -V (版本信息) 功能不同
-x (精确匹配整行) -X (排除文件/扩展功能) 功能不同

常见元字符表(Linux Metacharacter)

元字符（Metacharacter） 名称 介绍 示例
(空格) 空格 分隔命令、参数和选项。 ls -l
| 管道符 将前一个命令的标准输出作为后一个命令的标准输入。 ls -l | grep ".txt"
> 重定向输出（覆盖） 将命令的标准输出重定向到文件，会覆盖文件原有内容。 echo "Hello" > file.txt
>> 重定向输出（追加） 将命令的标准输出追加到文件末尾。 echo "World" >> file.txt
< 重定向输入 将文件内容作为命令的标准输入。 wc < file.txt
$ 变量引用 引用变量的值。 echo $HOME
# 注释 在脚本或命令中用于添加注释，该行 # 之后的内容会被忽略。 # This is a comment
* 通配符（Wildcard） 匹配任何零个或多个字符。 ls *.txt
? 通配符（Wildcard） 匹配任何单个字符。 ls file?.txt
[] 通配符（Wildcard） 匹配括号内列出的任何单个字符。 ls [abc].txt
& 后台执行 在后台运行命令，使终端立即返回。 sleep 60 &
() 子 Shell 在一个子 Shell 中执行命令列表。 (cd /tmp && ls)
; 顺序执行 按顺序执行多个命令，不关心前一个命令的成功与否。 cmd1 ; cmd2
&& 逻辑 AND 只有前一个命令成功（返回 0）时，才执行下一个命令。 cmd1 && cmd2
|| 逻辑 OR 只有前一个命令失败（返回非 0）时，才执行下一个命令 `command1
' 单引号（Single Quotes） 强引用，引号内的所有字符都按字面值处理，不进行任何转义或变量替换。 echo '$HOME'
" 双引号（Double Quotes） 弱引用，引号内的字符按字面值处理，但会进行变量替换和命令替换。 echo "$HOME"
` 反引号（Backticks） 执行命令，并将其标准输出作为另一个命令的参数。 echo "The current date is `date`"
\ 转义符（Escape） 用于取消元字符的特殊含义，使其按字面值处理。 echo "The path is C:\\Users"

“-”连字符的用法和意义

  1. 命令参数前缀
  2. 在 cd 命令里，- 代表“上一次所在的工作目录”。 cd -则会回到上次工作的目录
  3. 正则里表示范围 grep '[a-z]' file # 匹配任意小写字母
  4. 代表标准输入/输出（stdin/stdout）
    很多命令把单独的 - 当作“标准输入”或“标准输出”的占位符。
    cat - file.txt      # 先从标准输入读数据，再读 file.txt
grep "abc" -        # 从标准输入中搜索 "abc"
tar -czf - dir/ > archive.tar.gz   # 将 tar 输出写到 stdout，再重定向到文件
tar -xzf archive.tar.gz -C -       # 从 stdin 读取压缩包并解压
